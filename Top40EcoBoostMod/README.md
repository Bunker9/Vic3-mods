# Top40EcoBoostMod

First mod in the Vic3-mods repo. Economy-boost tweaks for Victoria 3.

## Structure
```
Top40EcoBoostMod/
├─ .metadata/metadata.json        Mod manifest (name, id, version, game version)
├─ events/                        Event scripts (*.txt)
├─ common/
│  ├─ scripted_effects/           Reusable effects ("scripts" that do things)
│  ├─ scripted_triggers/          Reusable conditions ("scripts" that test things)
│  ├─ script_values/              Named numeric values ("variables")
│  └─ modifiers/                  Static modifier definitions
└─ localization/english/          *_l_english.yml strings
```

Status: skeleton scaffold only — no gameplay content yet.
