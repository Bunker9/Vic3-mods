# PrettyTreatyMod - the people who staff each concession at 1836.
# HAND-WRITTEN.
#
# WHY: the province splits in zz_ptm_states.txt hand each grantee one bare port
# province with NO pops of its own, so the buildings in zz_ptm_concession_buildings.txt
# would stand empty. Vanilla's own treaty ports are pop-rich (GBR Singapore 124k,
# OMA Hormuz 64k, POR Macau 348k).
#
# SIZED FROM THE JOBS, NOT GUESSED. Package = 1 port + 3 trade centres + 1 tooling
# workshop + the manor house the engine raises once aristocrats and clergy exist:
#   port pm_anchorage        70 lab  /  20 clerk /  10 bur          (11_private_infrastructure.txt:7)
#   3x trade centre          2400 clerk / 600 shopkeeper            (11_private_infrastructure.txt:349)
#   tooling workshop         4500 lab / 500 shopkeeper              (01_industry.txt:933)
#   manor house              50 aristocrat / 100 clergyman          (11_private_infrastructure.txt:514, :571)
#   TOTAL                    4570 lab, 2420 clerk, 1100 shopkeeper, 10 bur, 50 arist, 100 clergy
#
# JOBS TO POP SIZE: divide by the working adult ratio. WORKING_ADULT_RATIO_BASE = 0.25
# (common/defines/00_defines.txt:1454), so pop = jobs x 4, EXCEPT aristocrats, which
# override to 0.2 (common/pop_types/aristocrats.txt:5) and so need jobs x 5.
# Full package therefore comes to ~33,050 people per concession.
#
# EVERY create_pop CARRIES AN EXPLICIT pop_type. Omitting pop_type is the vanilla idiom
# for bulk population, but it drops the pops in as unemployed subsistence peasants and
# the qualified jobs then fill only as literacy and wealth allow - clerks gate on
# literacy (common/pop_types/clerks.txt:52), shopkeepers on wealth (shopkeepers.txt:37),
# aristocrats on wealth and serfdom (aristocrats.txt:33). Naming the type puts each pop
# straight into the job it was counted for. Only laborers and peasants are ungated.
#
# CULTURE SPLIT: the labouring bulk is LOCAL, matching the host state's dominant pops. The
# whole MERCHANT AND CLERICAL class is the GRANTEE'S - shopkeepers and clergymen are entirely
# grantee culture and religion, alongside the bureaucrats, aristocrats and the settler clerks.
# A concession's shops and its church belong to the power that took it; a European chapel
# staffed by local clergy of another faith makes no sense.
#   local per concession    18,280 laborers + 7,680 clerks
#   grantee per concession   4,400 shopkeepers + 400 clergymen + 2,000 clerks
#                            + 40 bureaucrats + 250 aristocrats
# Totals are unchanged from the job maths above - only the culture assignment moved.
#
# RELIGION IS OMITTED ON LOCAL POPS so the culture default applies, which is what vanilla
# does for a state's dominant pops. The one exception is Oman, where the local norm is
# ibadi rather than the bedouin default of sunni, so it is stated. Grantee religions are
# stated explicitly and match the six already verified in common/scripted_effects/ptm_effects.txt
# plus AUS south_german/catholic, USA yankee/protestant, SAR north_italian/catholic.
#
# LOCAL CULTURES read out of common/history/pops/** per host state, not guessed:
#   Formosa min, Mekong vietnamese, Shengjing han, Fars persian, Oman bedouin/ibadi,
#   South Madagascar malagasy, Antioquia north_andean, North Borneo bornean,
#   Bas-Congo bakongo, Hail bedouin, Dongola bedouin, Somaliland somali.
#
# DELIBERATE OVERLAP, DO NOT "DEDUPLICATE": ptm_effects.txt's ptm_settle_concession_pops
# also creates pops. That is the RACE PRIZE for whoever wins the railway or mining
# decision, a separate one-off reward on top of this day-1 seeding. The two are not
# duplicates of each other.
#
# SAR / STATE_SOMALILAND IS SIZED FOR ITS REDUCED PACKAGE (1 port + 1 trade centre + the
# manor house): 70 lab, 820 clerk, 200 shopkeeper, 10 bur, 50 arist, 100 clergy = ~5,050.
# =============================================================================
