# =============================================================================
# PrettyTreatyMod - the 1836 concession treaties.
# HAND-WRITTEN. Shape copied verbatim from vanilla
# common/history/treaties/00_historical_treaties.txt (the Luso-Chinese / Macau treaty
# for the treaty_port article, the France-Egypt aid treaty for goods_transfer).
#
# ONE TREATY PER COUNTRY PAIR, carrying ALL of that pair's articles. No conditionals.
#
# Treaty ports, investment rights and goods supply are all TREATY ARTICLES - there is no
# create_treaty_port effect and no diplomatic pact for any of them.
#
# ARTICLE DIRECTION (easy to get backwards):
#   treaty_port                source = the HOST giving up the port, target = the European
#   foreign_investment_rights  source = the country invested IN, target = the investor
#   goods_transfer             source = whoever SENDS. Here the EUROPEAN supplies the host.
# One goods_transfer article PER GOOD. Engine minimum quantity is 10.
#
# NO DLC CHECK on foreign_investment_rights: the foreign_investment feature ships in the
# 1.13.9 free base patch, so gating on it is dead weight. (Vanilla still wraps its own
# treaties in has_dlc_feature if/else - that is legacy, do not copy it here.)
# RUS is the only pair with no investment rights: Shengjing is a port concession only.
#
# Both halves are required for a working treaty port: this file for the diplomatic object,
# and common/history/states/zz_ptm_states.txt for the day-1 province ownership. Verified
# in game 2026-07-20 - cede_treaty_port alone transfers land but creates no articles.
#
# Do NOT define the treaty_port ARTICLE here - SteadyInnovMod already REPLACE_OR_CREATEs it.
# =============================================================================
