# =============================================================================
# MyDiploPlayMod — give Punjab (c:PAN) a CLAIM ("core") on Sindh's only state at
# game SETUP. Additive state-history block (no create_state) — vanilla creates the
# state first (owner c:SIN); this just appends the claim + Punjabi homeland.
#
# WHY at setup (not via event): the start-of-game war goal is `return_state`, the
# LOWEST-infamy take-a-state goal (base infamy 2 vs conquer_state's 5). return_state
# is the "reclaim a state you have a claim on" goal, so the claim should exist when
# the war is created in history. (Mirrors the old FI-Light mod's add_claim = c:PAN.)
# This also gives easy post-war incorporation (Punjabi homeland) + low unrest.
# =============================================================================
STATES = {
	s:STATE_SINDH = {
		add_claim = c:PAN          # the "core" -> enables low-infamy return_state
		add_homeland = cu:panjabi  # easy incorporation + low post-conquest unrest
		debug_log = diplo_claim_row   # -> test report "Claims & cores" table
		debug_log = diplo_core_row
	}
}
